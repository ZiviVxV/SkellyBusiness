AANBEVOLEN CLIENT-SIDE MODS <br>
Je kan zelf mods/shaders/resource packs toevoegen met bijvoorbeeld CurseForge of Modrinth (of je eigen folder skills). Note: de server staat op 26.2, let op dat de client-side mods ook op 26.2 staan. Ik heb ook een modpack gemaakt met alles wat in dit document genoemd wordt: SkellyBusinessPack1.0.mrpack.
<br>
De enige mod die echt verplicht is om volledige functionaliteit te hebben op de server is 
Simple Voice Chat. Deze is (zowel client-side als server-side) nodig om in-game te chatten via  microfoon met andere players. Zonder de mod kun je voor de rest nog steeds spelen op de server.
  > modrinth link: https://modrinth.com/plugin/simple-voice-chat<br>
  > curseforge link: https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat
<br>
Render distance mods<br>
-	Bobby: als je hogere render distance wil dan de server
-	Voxy: laat extreme render distances toe zonder je computer te slopen. Note: stel wel de settings goed in; hoe hoger ‘Pixels^2 of subdivision size’, hoe minder zwaar voor je computer
<br>
Performance mods<br>
-	Better Block Entities
-	Dynamic FPS
-	Entity Culling
-	More Culling
-	FerriteCore
-	ImmediatelyFast
-	Ixeris
-	Lithium
<br>
Extra mods (slice-of-life)<br>
-	Chat Heads: laat de head van de player zien naast de username in de chat
-	Facebar: laat heads van players zien ipv. een kleur
-	LambDynamicLights: licht blokken geven al licht wanneer je ze in je hand hebt
-	Zoomify: inzoomen door op c te duwen
-	Skin Shuffle: als je meerdere skins hebt kun je in-game switchen
-	No Chat Reports: (privacy mod) zorgt ervoor dat Mojang/Microsoft niet je chatberichten kan tracken

Shaders<br>
Als je shaders wil toevoegen zou ik Iris Shaders aanbevelen om de shaders te laden. Qua shaders zelf gebruik ik Sildurs Enhanced Default Shaders en Sildurs Vibrant shaders, maar er zijn vele andere shaders.
<br>
Compatability mods<br>
Worden meestal vanzelf ge-download als je een modpack maakt via bijvoorbeeld  modrinth of curseforge, zijn nodig om mods samen te laten runnen zonder error: Cloth config API, Fabric API, Fabric Language Kotlin, YetAnotherConfigLib
<br>
SERVER-SIDE DATAPACKS <br>
-	Multiplayer sleep: als één iemand gaat slapen wordt het weer dag 
<br>
-	Name Colors: je kan de kleur van je naam in chat aanpassen met /trigger color
<br>
-	Custom Nether Portals: nether portals kunnen elke shape/grootte (van 4-200)  zijn & kunnen met crying obsidian
<br>
-	Mini Blocks: maak een mini-block door een block in een stonecutter te plaatsen
<br>
-	More Mob Heads: mobs hebben een kans om hun head (als item) te droppen
<br>
-	Player Head Drops: de head van een player dropt (als item) als de persoon word gekilled door een andere player 
<br>
-	Craftable Invisible Item Frames: maak item frames (de achtergrond) doorzichtig door ze in een crafting table te plaatsen
<br>
-	AFK display: Player naam wordt grijs na 5 minuten AFK
<br>
-	Name Formatting Station: Zorgt ervoor dat je de naam van items kan aanpassen met /trigger FormatName
<br>
-	Fast Leaf Decay: overgebleven leaves verdwijnen een stuk sneller dan normaal
<br>
-	Simple voice chat enhanced groups: /instantgroup range voegt iedereen aan 1 groep toe (waardoor iedereen elkaar kan horen)
<br>
-	Armor Statues: zorgt ervoor dat je armor stands kan poseren (tutorial: https://www.youtube.com/watch?v=nV9-_RacnoI)
<br>
-	Model Applier: zorgt ervoor dat je de look van een item kan aanpassen (tutorial: https://www.youtube.com/watch?v=3TwMcAqSHhs)
<br>
- Audioplayer: Je kan eigen audio kan uploaden op music discs, goat horns & noteblocks met heads (tutorial: https://modrinth.com/mod/audioplayer)
<br>
-	Audioplayer roleplay: Extra functies voor Audioplayer (https://modrinth.com/mod/audioplayer-roleplay)
